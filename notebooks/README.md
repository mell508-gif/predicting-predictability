# Notebooks

## Final analysis

The notebooks in `final/` are the final versions for the completed project:

1. `final/01_july_wraps.ipynb` — compound registry, embeddings, signature modeling, and the multimodal predictability pipeline (Steps 1–3).
2. `final/02_more_regression.ipynb` — Step 4 regression development, validation, and applicability analyses.
3. `final/03_step4_expanded_regression_moa.ipynb` — finalized expanded regression, mechanism-of-action, profile-depth, and scaffold analyses.
4. `final/04_predictability_direction_audit.ipynb` — final audit confirming predictability-score direction and downstream consistency.

## Running the notebooks

Start Jupyter from the repository root and run the notebooks in the order above. Their existing project-relative paths then resolve to the files under `data/`, `figures/`, and `models/`.
